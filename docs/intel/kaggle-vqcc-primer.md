## 0. 先に結論 (ワーカー向け、効きそうな順)

1. **スコア上の換算レート** [資料 p.57-58]
   - `[I]` S = Q·C なので、アンシラ 1 個の追加は Toffoli 換算で C/Q 個以上減らせるときだけ得 (自分の現行 Q, C を当てはめて計算する)。
   - `[II]` S = R·Q²·N_Toffoli なので、Q 1% 減は Toffoli 2% 減と同じ価値。qubit を増やす高速化 (並列化・メモ化) は損になりやすい。
   - `[III]` S = λ_eff·N_Toffoli·Q。N_Toffoli と Q は提出した角度回路だけでなく、ブロックエンコーディング全体で数える (kickmix で書けない部分は解析式で加算される)。自分の回路の削減が全体の何 % にあたるかで効果を見積もる。
2. **C はショット平均** `[I]` [資料 p.55-56]: HMR の結果 b は確率 1/2 で 1。`if b` の位相補正の中の Toffoli は C に 1/2 だけ寄与し、補正を Clifford だけで書けば寄与は 0。CNOT・CZ・X はスコアに入らないので、Toffoli を 1 個減らすためなら Clifford はいくら増やしてもよい。
3. **一時 AND を全面的に使う** `[全]` [資料 p.49-50, 63-64]: 計算側は Toffoli 1 個 (T 4 個相当)、解放側は `HMR` と `CZ a b if b0` だけで Toffoli はゼロ。通常の計算+逆計算に比べて Toffoli が半分になる。builder では `init_and` / `del_and` を使う。n ビット加算は Toffoli n−1 個 (carry 用アンシラ ~n 個)。
4. **検証は 3 条件を全ショットで見る** `[全]` [資料 p.67-68]: (1) 入出力のビット列、(2) 全アンシラが |0>、(3) 位相 (ターン単位) の一致。テスト入力は「回路ファイルの SHA-256 + 秘密 salt」から作られる。LB は別の salt で検証し直されるので、ローカルで通っても落ちうる。
5. **「たまに落ちる」なら HMR 補正漏れを疑う** `[全]` [資料 p.50-51]: 補正を忘れると、b=1 かつガーベジ=1 のショットでだけ符号が反転する。落ちる入力が毎回違うのが特徴。また、非 |0> の qubit を `R` で捨てると、シミュレータは bit=1 のとき符号をランダムに反転させる。ガーベジをこっそり捨てる手は使えない。
6. **invsqrt の誤差設計** `[I]` [資料 p.73-79]: 打ち切り乗算 (下位の部分積を計算しない) が主なレバーで、捨てた部分の桁上がりで誤差は単純な切り捨てより大きくなる。誤差予算は近似・Newton 打ち切り・丸め・部分積省略の 4 つに配分する。invsqrt は失敗 0 が必須なので、最悪誤差を解析で押さえて余裕を残す。範囲縮小の境目 (入力 2^{2k}−1, 2^{2k}, 2^{2k}+1) は必ずテストする。
7. **表引きか算術か** `[II][III][I]` [資料 p.37-39, 59-60]: QROM (unary iteration) は Toffoli 約 L 個 (L = 表の項目数) で、データ幅は CNOT にしか効かない。k ビット入力の関数は約 2^k Toffoli の表引きで、k が小さければ算術より安い。ウィンドウ化 (w 個の制御ビットをまとめて QROM で足す値を引く) で加算回数を 1/w にできる。
8. **ホットスポット探し** `[全]` [資料 p.65-66]: kickmix のシミュレータには SVG の flame chart 機能があり、入れ子のサブルーチンごとの Toffoli と qubit の内訳を出せる。ベースラインの組み込みサブルーチンのコストを測り、高い順に差し替える。

## 1. コンペの枠組み (PDF p.7-12)

- [資料] 3 タスク: invsqrt = 核融合 (1/√x に比例する位相をかける)、dqi = DQI (Reed-Solomon 符号の復号回路)、dfthcsos = 化学 (FeMoCo のハミルトニアン係数のロード回路)。
- [資料] 総合スコア = Π(S_ref/S_b)^{1/3}。Kaggle の「cost」は論文の「スコア S」(小さいほど良い)。1 タスクだけ S を半分にすると総合 2^{1/3} ≈ 1.26。どのタスクでも同じ相対改善は同じ価値で、コストの絶対値が大きいタスクが支配するわけではない。1 タスクを詰めるほど収穫が逓減するので、複数タスクに手を広げるほうが得になりやすい。
- [資料] 提出 zip は `invsqrt.kmb|.kmx`, `dqi.kmb|.kmx`, `dfthcsos/` (`angle_k_0`… を 0 から欠番なしの連番 + `submission.npz` = 分解と Givens 回転の木)。採点 1 回に約 45 分、提出は 1 日 5 回まで。
- [資料] 賞には単一タスク賞 (1 万ドル × 3、各タスクの最良コスト) もある。中間マイルストーン賞と最長首位賞はノートブックの公開が条件。

## 2. kickmix 回路と検証の原理 (PDF p.13-26, 41-46, 61-72)

- [資料] kickmix 回路は「置換行列 × 対角ユニタリ」(単項行列) のクラスに収まる。各基底状態 |x> は 1 つの基底状態と位相 e^{2πiθ} に写るので、ビット列 n ビットと位相 (実数) を追うだけでシミュレーションでき、時間はゲート数に比例する。線形性により、全計算基底で正しければ重ね合わせでも正しい。
- [資料] 測定 (HMR) の結果は乱数で固定してから追跡する。
- [資料] **ビット順はリトルエンディアン**: レジスタの 0 番目が最下位ビット (2^0)。回路図の線の番号とは別物。
- [資料] 位相の単位は**ターン** (1 ターン = 2π)。`Z_POW t` は |1> に e^{iπt} をかける (t=1 → Z、t=0.5 → S、t=0.25 → T)。`NEG` はグローバル位相 −1 で、条件付きにすると位相補正に使える。単位の取り違えはビット列に出ないバグになる。
- [資料] 命令セット (表7.1): X, CX, CCX, Z, CZ, CCZ, Z_POW, NEG, SWAP, CSWAP, R, HMR / BIT_INVERT, BIT_STORE0, BIT_STORE1 / PUSH_CONDITION, POP_CONDITION / REGISTER, APPEND_TO_REGISTER, DEBUG_PRINT, INFO_TAG。条件は命令末尾の `if b` か PUSH/POP の条件スタック (ネスト可) で付ける。
- [資料] builder: `init_and(a,b,tmp)` (R + CCX)、`del_and(a,b,tmp)` (HMR + `CZ a b if b0`、qubit は解放しない)、`free(tmp)` (命令は出さず、builder 内の再利用を許可するだけ)。制御に古典ビットを渡すと古典条件付きの安い命令に、定数 False を渡すと命令そのものが省略される (定数畳み込み)。使い終わったレジスタはすぐ free すると Q が減る。
- [資料] 一時 AND の .kmx: `R q3 / CCX q0 q1 q3 / CX q3 q2 / HMR q3 b0 / CZ q0 q1 if b0`。
- [資料] CCZ と Toffoli は標的を H で挟むと互換で、コストは同じ。Toffoli は T 7 個相当、一時 AND の計算側は T 4 個相当。
- [資料] 位相オラクル |x> → e^{2πi c f(x)}|x> の作り方: f(x) を固定小数点で計算 → 各ビット y_k に Z の t_k = c·2^{k+1} 乗 → 逆計算。コストの大半は計算と逆計算。小数部 ℓ は 2^{−ℓ} ≤ 許容誤差を満たす最小値で足り (例: 1e-7 → ℓ=24)、それより下の桁を計算してもゲートが増えるだけ。
- [資料] 位相キックバック: 標的を |−> にした XOR オラクルは (−1)^{f(x)} を入力側の位相として返す。

### 検証器 (第8章)

- [資料] 流れ: 提出 .kmb の SHA-256 + 秘密 salt → seed → 指定分布 (|α_x|²) から入力を生成 → シミュレーション → 3 条件をチェック → 合否と失敗率の上界。salt は後日公開され、誰でも再現できる。
- [資料] salt の目的は seed grinding (何もしない命令を足してハッシュを変え、易しい入力が出る seed を探す) の防止。回路が 1 バイト変わるとテスト入力が総入れ替えになる。
- [資料] 入力分布は仕様の一部。振幅の大きい入力での誤りは致命的。
- [資料] 失敗率の上界: N 連続成功なら ε+ ≈ 128·ln2/N ≈ 88.7/N (δ = 2^{−128})。N=10,240 で <1%、N=102,400 で <0.1%。テスト回数は入力 qubit 数に依存しない。
- [資料] 定理 8.1: HMR と R が「他の qubit の関数になっている qubit」にだけ作用するなら、失敗率 ε に対して出力状態と理想状態のトレース距離は 2√ε 以下。
- [資料] 失敗の扱いは 2 通り。invsqrt と dfthcsos は失敗 0 が必須 (dfthcsos は有効アドレスごとに 64 回ずつテストし、1 回でも失敗すれば不合格)。dqi は失敗を許し、そのぶんを R(ε+) でスコアに反映する。
- [資料] invsqrt の検証は 1 ≤ x ≤ 3,133,452 の全入力 × 64 回 (計 200,540,928 ショット) で、C はその平均。
- [資料] コラム: 検証器自体にバグがありうる。過去の ECC 資源見積もりでは、Trail of Bits が検証コードの不備を突いて、本物の改善と見分けのつかない「証明」を作った。
- [推論] これらは AGENTS.md の禁止事項 (verifier の穴・特定 seed/salt でだけ通る回路の禁止) と同じ方向。低確率の入力域だけで誤る回路は検証を通り得ても、手動審査と別 salt の再検証で落ちる前提で扱う。

## 3. コストモデル (PDF p.52-60)

| タスク | S (小さいほど良い) | 補足 [資料] |
|---|---|---|
| invsqrt | Q × C | C = N_Toffoli + N_T/4 (ショット平均)。T 4 個 = Toffoli 1 個 |
| dqi | R(ε+) × Q² × N_Toffoli | R(ε) = ln2 / (−ln(1/2 + 2√ε))。ε+=0 で R=1、ε+→1/16 で R→∞ |
| dfthcsos | λ_eff × N_Toffoli × Q | λ_eff = √(E_gap(2Λ − E_gap))。N_Toffoli と Q はブロックエンコーディング全体で数える |

- [資料] 表面符号では論理 qubit 1 個 ≈ 2d² 物理 qubit。非 Clifford ゲート (T, Toffoli, CCZ, 任意角回転) はマジックステートを消費するので高い。Clifford は安い。
- [資料] 時空体積 ≈ 論理 qubit 数 × 実行時間。論文は qubit 数と Toffoli 数を物理コストの粗い代理指標としている。
- [資料] 一般的な小型化手法 (第6.5節、主催者推奨ではなく一般論と明記):
  - 測定による解放 (一時 AND)
  - 定数の畳み込み
  - 部分式の共有 (qubit と gate のトレードオフ)
  - ウィンドウ化 (QROM で足す値を引いて加算回数を 1/w に)
  - 近似算術 (影響しない下位ビット・稀な桁上がり・反復の打ち切り。可否は検証条件次第)
  - 計算か表引きか
  - 数の表現選択 (2 の補数 / 符号絶対値 / 1 の補数で加算・比較のコストが変わる)
  - 早期解放と計算順序の入れ替えで Q を減らす
- [推論] ハーネスの BRIEF_OVERVIEW §1 のスコア式 (公式 metric notebook と verifier から確認したもの) と矛盾しない。細部 (Z_POW の T 換算など) は verifier の実装が正。

## 4. 算術回路の Toffoli 数 (PDF p.27-40, 表3.12)

| 演算 | Toffoli (一時 AND = 1 と数える) | 出典 [資料] |
|---|---|---|
| 加算 a+b | 2n−1 (アンシラ 1) / n−1 (アンシラ n) | Cuccaro (quant-ph/0410184) / Gidney (Quantum 2:74, arXiv 1709.06648) |
| 比較 a<b | 2n−1 / 約 n | Cuccaro / Sanders+ (PRX Quantum 1, 020312) |
| 定数加算 a+k | n−2 (n≥2)、定数用の qubit は不要 | Sanders+ |
| 整数乗算 | 2n²−n | Sanders+ |
| 固定小数点乗算 (d ビット精度) | d²−d−1 (下位の部分積を捨てる) | Sanders+ |
| 二乗 (d ビット精度) | d²/2 − 5/2 (d 奇数) / d²/2 − 4 (d 偶数) | Sanders+ |

- [資料] 比較は差の全ビットは不要で、アンダーフローの 1 ビットだけ計算して CNOT でコピーし逆計算する。
- [資料] 定数との AND は、定数のビットが 0 なら何もせず、1 なら入力をそのまま使う (ゲート省略)。定数倍 k·a は k の 1 のビット位置だけ加算する。
- [資料] Bennett の逆計算はゲート数がおよそ 2 倍になる。アンシラを増やせば再計算が減る (計算と記憶のトレードオフ)。

## 5. invsqrt 向け: 近似計算 (PDF p.73-79) `[I]`

- [資料] 固定小数点: m ビット・小数部 ℓ ビットで、値は y/2^ℓ。乗算は整数積を ℓ ビット右シフトしたもの。下位の部分積を計算しなければ Toffoli が減るが、桁上がりの分だけ誤差は単純な切り捨てより大きい。
- [資料] 多項式近似: Horner 法で d 次は乗算 d 回 + 加算 d 回 (係数は古典定数なので安い)。区間全体の最大誤差を下げるなら Taylor ではなく Chebyshev かミニマックス (Remez) を使う。
  - 1/√x の 3 次近似: [1,4] で Taylor は端で約 5%、Chebyshev は最大約 0.9%。[2,4] に狭めると約 0.05%。
- [資料] 区分多項式: 入力の上位ビットをアドレスにして QROM で係数を引く。区間を増やすと QROM のコストが増え、減らすと次数が増える (トレードオフ)。最小化すべきは平均二乗誤差でなく最大誤差。
- [資料] Newton 法: y ← y(3 − x y²)/2 で割り算なし、1 回に乗算 3 回。誤差は e' ≈ −1.5e² (2 次収束)。初期誤差 1% なら、反復 0/1/2/3 回でそれぞれ約 7/13/25/49 ビット。24 ビットが目標なら「初期値 12 ビット + Newton 1 回」か「7 ビット + 2 回」。コンパニオン論文によると、ベースラインは「良い初期値 + Newton 1 回」を固定小数点で再現した構成。
- [資料] 範囲縮小: x = 2^{2k}·m, m∈[1,4) とし 1/√x = 2^{−k}/√m。k が重ね合わせなので、シフトは制御付きシフトの組合せになりコストがかかる。指数を偶数にそろえるのは √(2^{2k}) = 2^k を整数シフトで済ませるため。境目 (2^{2k}−1, 2^{2k}, 2^{2k}+1) は先頭ビット検出や偶奇合わせで 1 ビットずれやすい。
- [資料] 誤差予算: 許容誤差 1 つを、近似誤差・Newton 打ち切り・丸め・部分積省略に配分する。一部を上げすぎるとゲートの無駄になる。検証器があるので許容ぎりぎりまで攻められるが、検証は有限回なので「たまたま通った」状態を狙うのは危険。失敗 0 必須のタスクでは、最悪誤差を理論的に解析して安定して合格する回路を作る。
- [推論] 設計空間は (区間数, 次数, 係数ビット幅, Newton 回数, 各段の乗算ビット幅, 部分積の省略列数) で、最悪誤差の上界を解析的に出してから quick/full にかける。

## 6. dqi / dfthcsos 向けの記述 `[II][III]`

- [資料] この資料には、dqi の GF(2^k) 算術や dfthcsos の QROM・Toffoli 内訳など、タスク固有の具体的なゲート数はほぼ無い。
- [資料] dqi は失敗を許すタスク。「少し失敗するが大幅に安い回路」と「失敗しない高い回路」を R(ε+) 込みのスコアで比べる。ε+ が 1/16 に近づくと R が発散する。
- [推論] dqi: Q² が効くので qubit 削減を最優先で評価する。小さい体の逆元・乗算は QROM の表引きと算術を比べる。失敗を許す近似は、本物の近似・誤り率として成り立つ範囲に限る (手動審査がある)。
- [推論] dfthcsos: 角度ローダの Toffoli はほぼ表サイズ L で決まり、データ幅は CNOT にしか効かない。同じ unary iteration で複数の角度ビットをまとめて書く、窓幅を調整する、すぐ free して Q を削る、が基本の方向。全体 (ブロックエンコーディング) の何 % を自分の回路が占めるかを先に見積もる。
